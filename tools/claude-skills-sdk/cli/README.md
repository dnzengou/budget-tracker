# claude-skills (Rust CLI)

Single-binary cross-platform CLI. Bundles the 6 skills via `rust-embed`.

```bash
cargo install --path cli
claude-skills list
claude-skills show kafca
claude-skills compose rrss kafca > system.txt
```

Pre-built binaries: see [releases](https://github.com/dnzengou/claude-skills-sdk/releases) (linux/macos/windows × amd64/arm64).
