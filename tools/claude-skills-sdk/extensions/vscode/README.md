# Claude Skills — VS Code Extension

Insert and compose Claude skill prompts inside any text editor.

## Commands

- `Claude Skills: Insert Skill Prompt` — pick one skill and insert at cursor
- `Claude Skills: Compose Multiple Skills` — pick several, joined with `---`
- `Claude Skills: List Bundled Skills` — show available skill ids

## Settings

- `claudeSkills.defaultStack` — array of skill ids to auto-compose. Default `["kafca", "rrss"]`.

Install from VS Code Marketplace (publisher: dnzengou) or sideload the `.vsix` from [releases](https://github.com/dnzengou/claude-skills-sdk/releases).
